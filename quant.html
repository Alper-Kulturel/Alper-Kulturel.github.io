Focus
Pricing · Risk · Backtesting

Every model in this folder starts from the mathematics and ends in a number that can be checked. Options are valued three independent ways — closed form, lattice and simulation — so the implementations validate each other rather than being trusted on faith. Backtests model the costs that real execution imposes, because a strategy that only works at zero slippage does not work.

The through-line is reproducibility: assumptions stated up front, benchmarks published alongside results, and code written to be read by whoever inherits it. Where a result is unflattering — a strategy that fails its significance test, a model that only holds in-sample — it stays in the write-up.
