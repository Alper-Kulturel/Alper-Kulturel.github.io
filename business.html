This is the consulting shelf: three engagements taken from a business question to a costed recommendation. Each one starts with the decision someone has to make — where a firm’s margin is leaking, whether a market is worth entering, which step in a process is the constraint — and ends with a number attached to the answer.

Every project runs end to end on a seeded dataset: the pipeline executes, the charts are generated, and the findings in the README are the output of that run rather than a narrative written around it. The analysis is deliberately conservative — assumptions are stated, sensitivities are shown, and where two sizing methods disagree, both numbers are kept.

File 03 entries
engagement-profitability-analytics Python · pandas · SQL Decomposes a consulting firm’s margin into discounts, write-offs, unbilled time and delivery cost, then sizes what recovery is worth.
market-entry-analysis Python · pandas · Scenario Modelling Triangulates TAM/SAM/SOM top-down and bottom-up, scores segment attractiveness, and returns a go/no-go with phased entry modes.
operations-bottleneck-analysis Python · pandas · Process Mining Mines a process event log to find the real constraint, then simulates the fixes and prices each one as an investment with a payback.
