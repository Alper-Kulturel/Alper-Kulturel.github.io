Seven files about turning raw records into decisions. Credit risk scored at the loan level, churn predicted before it happens, sentiment scraped from the financial press and tested against what the market did next — each one shipped with its reasoning left visible.

The through-line is interpretability. A model that cannot explain itself is not finished, so every project carries its feature engineering, its validation, and its failures in the open.

File index 07 items
  • credit-risk-scoring Python · XGBoost · SHAP PD/LGD/EAD framework producing Expected Loss, credit grades, and Basel capital requirements.
  • banking-churn-predictor Python · scikit-learn · SHAP End-to-end ML pipeline with class imbalance handling and interpretable predictions.
  • sentiment-analyzer Python · VADER · FinBERT Scrapes financial RSS feeds, scores sentiment, and tests its predictive power against next-day returns.
  • market-data-etl Python · PostgreSQL · SQL Twenty advanced SQL queries over two years of S&P 500 daily data, using window functions and CTEs.
  • fpa-variance-dashboard Streamlit · Plotly Price, volume, and mix decomposition for budget versus actuals.
  • sales-dashboard Streamlit · Plotly RFM segmentation, cohort retention, ABC analysis, and the effect of discounting on margin.
  • financial-reporting-pipeline Python · SQLAlchemy · xlsxwriter End-to-end ingest, validate, load, compute KPIs, and emit a formatted Excel report.
