Latency · Data Structures · Parsing

The models in the other folders assume the numbers arrive on time. These three projects are about earning that assumption. A dependency-free Black-Scholes library that prices a scalar option in 38.8 nanoseconds and binds cleanly into Python with pybind11, so the fast path and the readable path are the same code.

The matching engine implements true price-time priority, holding O(log n) insertion and O(1) cancellation at roughly 67 nanoseconds per insert. The feed handler parses the ITCH binary protocol and is benchmarked at p50 and p99 rather than on averages, because tail latency is the number that actually breaks a trading system — and it ships with an ablation study showing which optimisations paid for themselves and which did not.
