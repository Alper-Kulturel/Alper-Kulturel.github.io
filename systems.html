Four files concerned with what happens underneath. The pricing and matching logic from the Quant folder appears here again, this time read as engineering: data structures with stated complexity, measured latency, and a live pipeline that has to stay correct while the market is open.

The C++ work is compiled, benchmarked, and exposed to Python through pybind11 — fast where it matters, readable everywhere else. The pipeline batches, deduplicates, and survives a reconnect.

File index 04 items
  • cpp-black-scholes C++17 · pybind11 · CMake Analytical option pricer exposing all five Greeks, with implied volatility solved by Newton–Raphson.
  • cpp-order-book C++17 · pybind11 Price–time priority matching engine with O(log n) add, O(1) cancel, and partial fills.
  • cpp-feed-handler C++17 · pybind11 · ITCH Low-latency market data parser for the ITCH binary protocol, benchmarked at p50 and p99.
  • crypto-data-pipeline Python · WebSocket · PostgreSQL · Docker Live Binance trade ingestion with batching and deduplication.
